Option 1: Use clip-path (Recommended for "Wipe" Reveals)
If you want a clean reveal from one side to the other, clip-path is the modern standard. It is more performant than masking and transitions perfectly.

Are you aiming for a sharp door-slide effect or a faded, soft-edge reveal?

Here is the breakdown of what those terms actually look like in code:
1. The Wipe (Literal Slide)
This is what most people mean. It looks like a curtain opening.
How it works: It uses clip-path: inset() to literally "un-crop" the image.
Visual: A sharp, vertical or horizontal line moves across the screen to show the color underneath.
2. The Wave (Organic/Moving)
If you want an actual wave shape (like water or a squiggle) moving across:
How it works: You need an SVG shape of a wave. You then animate the mask-position of that SVG across the element.
Visual: The leading edge of the reveal is bumpy or curvy rather than a straight line.
3. The Fade Wipe (Soft Edge)
This is a "wipe" but with a blurry, soft edge.
How it works: This uses the mask-image gradient trick I mentioned earlier.
Visual: The color "bleeds" in softly from one side to the other.
Which one are you going for? If you want that wavy/liquid look, I can show you how to plug an SVG into your mask-image instead of a gradient.

The "Magical Wave" Reveal
This approach uses a custom SVG wave as the mask-image. By making the mask wider than the element (mask-size: 200% 100%), we can transition its position from the transparent "hidden" side to the solid "visible" side. 
css
.color-reveal {
  position: absolute;
  top: 0; left: 0; right: 0; bottom: 0;
  background: url('homeback16x9.jpg') center center/cover no-repeat;
  z-index: 1;
  pointer-events: none;

  /* 1. Use an inline SVG for the wave. 
     This SVG is half-transparent (the wave edge) and half-solid black. */
  mask-image: url("data:image/svg+xml,%3Csvg xmlns='http://w3.org' viewBox='0 0 200 100' preserveAspectRatio='none'%3E%3Cpath d='M0,0 L100,0 C80,25 120,75 100,100 L0,100 Z' fill='black'/%3E%3C/svg%3E");
  
  /* 2. Standardized mask properties */
  mask-size: 200% 100%;
  mask-repeat: no-repeat;
  
  /* 3. Start with the 'empty' side of the mask visible (hidden state) */
  mask-position: 100% 0;
  
  /* 4. Smooth transition for the 'wipe' effect */
  transition: mask-position 0.8s cubic-bezier(0.4, 0, 0.2, 1);
}

1. The JavaScript (Put this in core.js)
This script checks which page you are on, "unlocks" that word in the browser's memory, and then checks if all three are unlocked to trigger the full reveal.
javascript
document.addEventListener('DOMContentLoaded', () => {
  // 1. Get the current "Unlock" status
  let unlocks = JSON.parse(localStorage.getItem('moms_art_unlocks')) || { missy: false, art: false, gallery: false };

  // 2. Which page are we on? Unlock the corresponding word.
  const path = window.location.pathname.toLowerCase();
  
  if (path.includes('aboutme')) unlocks.missy = true;
  if (path.includes('contact'))  unlocks.art = true;
  if (path.includes('gallery'))  unlocks.gallery = true;

  // 3. Save the new status
  localStorage.setItem('moms_art_unlocks', JSON.stringify(unlocks));

  // 4. Apply the "Partial" colors to the title spans
  if (unlocks.missy)   document.getElementById('wordMissy')?.classList.add('unlocked');
  if (unlocks.art)     document.getElementById('wordArt')?.classList.add('unlocked');
  if (unlocks.gallery) document.getElementById('wordGallery')?.classList.add('unlocked');

  // 5. THE GRAND FINALE: If all 3 are true and we are on Index
  if (unlocks.missy && unlocks.art && unlocks.gallery) {
    const reveal = document.querySelector('.color-reveal');
    if (reveal) reveal.classList.add('active');
  }
});
